# Отрисовка синей линии — 01.11.2026

Плановый маршрут целиком добавляется после расчёта и отображается синим.
Пройденная часть обновляется по мере движения скорой.
Линии маршрута переведены с Canvas на отдельный SVG-слой без обрезки
геометрии по текущему экрану (noClip). Это устраняет зависимость обновления
следа от перерисовки областей Canvas при перемещении карты.
Слой пробок остаётся на Canvas, выше него находятся линии маршрута.
Модель скорой, маячки, ETA и алгоритмы не изменены.

Все 9 JavaScript-наборов прошли, включая проверки обновления следа без
перемещения карты, обратной перемотки и отключения обрезки геометрии.
Проверки выполнены с DOM/Leaflet-адаптерами, без полноценного браузера.
Результаты: validation/route_display_javascript_tests.txt.
