# Исправление исчезнувшей синей линии — 01.11.2026

Причина: после перевода маршрута на SVG глобальное правило `svg {width:25px;
height:25px; ...}` для иконок применялось также к SVG-контейнеру Leaflet.
CSS перекрывал размеры, которые задаёт Leaflet, уменьшая слой до 25×25 пикселей.

Правило ограничено иконками интерфейса с aria-hidden="true". SVG карты теперь
использует размеры Leaflet. Собственные стили модели скорой сохранены.
Версия ресурсов увеличена, чтобы браузер загрузил исправленный CSS.

Все 10 JavaScript-наборов прошли. Добавлены проверки изоляции CSS иконок
от SVG карты. Полная браузерная проверка не выполнена: установка Chromium
не удалась (сервер загрузки возвращает неполный архив). Это статические
CSS-проверки и существующие проверки логики с DOM/Leaflet-адаптерами.
Результаты: validation/route_css_javascript_tests.txt.

Распакуйте архив в отдельную папку, остановите старый процесс и запустите
START_WINDOWS.bat. Если вкладка осталась открытой, обновите её Ctrl+F5.
