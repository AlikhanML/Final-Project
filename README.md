# Qadam · Астана

Qadam — Астана картасында жедел жәрдем бағытын жоспарлауға және қозғалысын симуляциялауға арналған оқу жобасы. Қосымша шақырту орнына апаратын маршрут пен болжамды жету уақытын көрсетеді. Кептеліс қабаты Астананың қарбалас уақытына негізделген модельді көрсетеді.

## Жобаны жүктеу

GitHub-та **Code → Download ZIP** батырмасын басып, архивті толық шығарыңыз. `app.py`, `requirements.txt` және `START_WINDOWS.bat` тұрған буманы ашыңыз. Астананың толық жол базасы жобамен бірге келеді.

## Windows жүйесінде іске қосу

1. [Python 3.12](https://www.python.org/downloads/) орнатыңыз. Орнату кезінде **Add Python to PATH** жалаушасын белгілеңіз.
2. Ашылған жобаның ішіндегі `START_WINDOWS.bat` файлын екі рет басыңыз. Алғашқы іске қосқанда файл `.venv` виртуалды ортасын құрып, кітапханаларды орнатады. Бұл қадамға интернет керек.
3. Браузер автоматты ашылмаса, консольдегі **Local URL** мекенжайын ашыңыз. Әдетте ол [http://localhost:8501](http://localhost:8501) болады.

Серверді тоқтату үшін консольде **Ctrl+C** басыңыз.

## Қолданбаны интернетте сілтемемен бөлісу (Windows)

1. [Cloudflare сайтынан](https://developers.cloudflare.com/tunnel/downloads/) Windows 64-bit нұсқасын жүктеңіз. `cloudflared-windows-amd64.exe` файлын `QADAM_SHARE_LINK.bat` тұрған бумаға қойыңыз.
2. `QADAM_SHARE_LINK.bat` файлын екі рет басыңыз. Қажет болса, ол `START_WINDOWS.bat` арқылы Qadam-ды іске қосады.
3. Консольде шыққан `https://…trycloudflare.com` сілтемесін көшіріп, бөлісіңіз. Телефоннан да осы сілтеме арқылы ашуға болады.

Бұл уақытша сілтеме. Бөлісіп тұрған кезде Qadam мен Cloudflare консольдерін ашық қалдырыңыз. Туннельді қайта іске қосқанда жаңа сілтеме беріледі.

## macOS немесе Linux жүйесінде іске қосу

`app.py` тұрған бумада терминал ашып, мына командаларды орындаңыз:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Консоль көрсеткен **Local URL** мекенжайын браузерде ашыңыз.

## Маршрутты байқап көру

1. Картадан Астана ішіндегі шақырту нүктесін таңдаңыз. Аурухана автоматты түрде таңдалады.
2. Маршрут пен болжамды уақыт шыққанда басымдықты таңдаңыз.
3. **Маршрутты бастау** батырмасымен симуляцияны қосыңыз.

## Тесттерді іске қосу

Windows-та бірінші іске қосудан кейін `RUN_TESTS_WINDOWS.bat` файлын ашыңыз. macOS және Linux жүйесінде виртуалды ортаны қосып, жоба бумасында `python run_tests.py` командасын орындаңыз.

Картамен, интерфейспен және алгоритмдермен байланысты қосымша құжаттар [README_KZ.md](README_KZ.md) файлында берілген.
